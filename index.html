estudio automático.

Studio se ejecuta en Windows y abre su interfaz en tu navegador. Une, monta y exporta desde ese mismo estudio.

WINDOWS X64

Elite Editor Studio

Beta v0.3.0-beta.5 · Descomprime el ZIP en una carpeta.

Descargar ZIP para Windows ↓ Guía de instalación ↗
  1. Instala Node.js 24+ y añade FFmpeg y ffprobe al PATH.
  2. Extrae todo el ZIP a una carpeta y ejecuta INICIAR_ESTUDIO.cmd.
  3. La pestaña del estudio automático se abre al arrancar.

El ZIP incluye la interfaz preparada. Para montar grabaciones con audio, configura Whisper desde la guía.

Preguntas frecuentes

¿Necesito una cuenta?

Studio utiliza una cuenta local para tus proyectos.

¿Cómo cambio el aspecto de Studio?

En el menú Tema visual del estudio instalado puedes elegir Azul cobalto o Lima. Los dos temas incluyen las mismas herramientas de montaje automático.

¿Qué puedo hacer sin Whisper?

Unir clips, editar a mano y exportar con FFmpeg. Whisper permite transcribir y montar de forma automática grabaciones con audio.

¿Puedo mover un montaje a otro equipo?

Usa Paquete .zip en Studio para guardar el montaje y los recursos que utiliza. Puedes recuperarlo desde la galería multimedia.

¿Dónde están mis proyectos del editor web anterior?

Siguen en el navegador donde los creaste. Editor manual (sin automatización) ↗
